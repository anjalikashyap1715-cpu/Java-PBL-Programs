# Java PBL Programs

This repository contains five Java programming projects completed as part of my BTech CSE coursework.

## Projects

1. **PBL 1 – Student Performance:** Calculates and displays student performance.
2. **PBL 2 – Bank Account:** Demonstrates basic bank account operations.
3. **PBL 3 – Electricity Bill:** Calculates an electricity bill.
4. **PBL 4 – Library System:** Demonstrates basic book management.
5. **PBL 5 – Employee Payroll:** Calculates employee salary details.
